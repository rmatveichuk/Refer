# Refer — AI-Powered Visual Asset Manager 🏛️

**Refer** — это интеллектуальный инструмент для управления локальными библиотеками архитектурных референсов. Разработан для CGI-специалистов, архитекторов и дизайнеров, которым важна скорость поиска и приватность данных.

![Refer Icon](icon.ico)

## ✨ Ключевые возможности

*   **🧠 Семантический поиск (SigLIP):** Ищите референсы по смыслу, а не по названиям файлов. Запросы вроде *"минималистичный бетон в мягком закатном свете"* работают мгновенно.
*   **🖼️ Поиск по сходству (Image-to-Image):** Перетащите любое изображение в программу, чтобы найти похожие по композиции, цвету или стилю в вашей библиотеке.
*   **🔌 Полный оффлайн:** Все вычисления нейросетей происходят на вашей видеокарте или процессоре. Никаких облачных API и подписок.
*   **🗂️ Умная каталогизация:** Автоматическое создание векторов для каждой картинки, поддержка тегов и фильтрации по категориям.
*   **🌍 Авто-перевод:** Пишите запросы на русском или английском — встроенная система перевода поймет вас.

## 📦 Быстрый старт

### Для пользователей (Windows)
Просто скачайте последний релиз из раздела **Releases** и запустите установщик `Refer_Setup.exe`. Программа автоматически подготовит окружение и предложит скачать необходимые веса моделей при первом запуске.

### Для разработчиков
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/user/refer.git
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   .venv\Scripts\python.exe main.py
   ```
   На Windows можно открыть `run.cmd` двойным кликом — он использует окружение проекта независимо от текущей папки терминала. В VS Code откройте папку проекта и выберите конфигурацию F5 `Refer (project .venv)`.

   Глобальный Python может содержать несовместимые версии NumPy и FAISS. Для запуска используйте `.venv`, где зависимости устанавливаются из `requirements.txt`.
