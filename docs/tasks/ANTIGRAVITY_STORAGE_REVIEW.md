# Задание Gemini 3.8 Flash в Antigravity: проверка скрытия и восстановления

Работать в этом проекте параллельно с Codex. Пользователь хочет экономить квоту Codex. Код уже меняется; не редактировать файлы реализации и не проводить операции с рабочей библиотекой.

## Цель

Независимо проверить очередной этап: «Скрыть из библиотеки» и восстановление без удаления SQLite, тегов, избранного, векторов и физических файлов. Просмотр недоступных файлов должен быть диагностикой, а не автоматическим удалением. Каталоги уже отключаются обратимо через настройки.

## Файлы для чтения

`database/visibility_store.py`, `database/search_repository.py`, `ui/hidden_assets_dialog.py`, `ui/main_window.py`, `ui/widgets/gallery_view.py`, `ui/widgets/top_toolbar.py`, `ui/catalog_dialog.py`, связанные тесты. Новые файлы могут появиться после начала задания — сначала проверить их наличие.

## Проверки

1. Все пути пользовательского удаления вызывают скрытие, включая галерею, таблицу и просмотр. Ветка без главного окна не должна стирать файлы или использовать неопределённые переменные.
2. Скрытие исключает изображение из семантического поиска, метаданных, тегов, избранного, ТОП и всех разделов. Очистка запроса/фильтров не возвращает его.
3. Восстановление возвращает прежние теги/избранное/вектор, без повторного импорта или инференса. Отключённый каталог остаётся отключённым после восстановления изображения.
4. Повторное сканирование не возвращает скрытые изображения и не размножает записи.
5. Ошибка записи файла состояния не сообщает успех и не повреждает предыдущее состояние. Чтение повреждённого состояния не должно молча сбрасывать скрытие.
6. Смена библиотеки с повторным использованием ID не должна скрывать другое изображение. Проверить привязку к идентичности записи.
7. Диагностика различает отсутствующий файл и недоступный источник/диск/UNC/PermissionError. Нет автоматического удаления при отключённом диске. Диагностика не изменяет SQLite или FAISS.
8. Ограничения: бюджеты миниатюр не относятся к полноразмерному просмотрщику/модели; старые tombstones и старые дубли не исправляются автоматически.

## Разрешённый результат

Запустить изолированные тесты на временных данных. Живую SQLite открывать только `mode=ro` при необходимости; не запускать `DatabaseManager` на ней, чтобы не инициировать миграции. Не менять окружение, не переиндексировать, не собирать EXE, не обращаться к LM Studio. Не создавать ассеты для скачивания вне кеша Refer.

Записать найденные воспроизводимые проблемы, их важность и рекомендации в `docs/research/STORAGE_REVIEW_REPORT.md`. Если проблем нет, привести конкретные выполненные проверки и ограничения. Не утверждать отсутствие ошибок без проверки. Код и тесты реализации не менять, коммитов не делать. Сообщить пользователю путь отчёта для передачи Codex.
